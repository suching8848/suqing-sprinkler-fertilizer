# 蘇清的灌溉养护模组 / SuQing’s Irrigation Care Mod

中文 | [English](README.en.md)

![Irrigation Care cover](publishing/preview.png)

为 Water Pipes 增加水泵集中供肥供药、喷洒器自动养护、独立管理窗口和可重复装填的药剂包。当前 **1.0.0**，支持 **Build 42.21 单人**。用户已反馈当前单人游玩正常，本地正式版准备已完成；创意工坊条目尚未上传。

## 前置与补丁关系

唯一必需的外部模组是 **Water Pipes / `Waterpipes`**。本模组不依赖 Batch Farming、Neat Crafting 或其他蘇清模组，Neat Crafting 的分类图标属于可选界面适配。

[蘇清的僵尸毁灭工程补丁合集](https://github.com/suching8848/suqing-project-zomboid-patches/) 按需单独启用，不是本模组的强制前置。集合中的 `SuQingBatchFarmingMenu_4221` 仅筛选 **Batch Farming** 的菜单，只有使用 Batch Farming 时才有意义，不参与本模组的水泵、供料或施肥逻辑。

## 管理与自动养护

右键水泵或喷洒器 → **管理水泵／喷洒器养护**。独立窗口显示五类库存、容量、单次消耗、开关和来源，可输入份数、装满或取回；操作后保持打开，装满显示提示。只使用背包及随身包内未收藏的物品。

每类容量：**喷洒器 200 份，水泵 1000 份**。化肥、霉菌、虫害（苍蝇）、蚜虫、蛞蝓分别计量和开启。支持原版化肥袋及对应药剂；三种原版喷雾用空立即返还空喷壶，部分装入保留剩余药剂。旧版寄存喷壶有余额时才显示领取按钮。

开启水泵对应供料项后，畅通管网上的喷洒器在**实际喷水**时使用水泵库存。遵循水管端口、楼层、分支和阀门，无水、停泵、断管不取用该泵。只允许水/污水水源。管网优先，来源不足时使用已开启的本机库存；可以关闭单个喷洒器接收管网。多个泵按稳定设备 ID 顺序选择余额足够的一台，不将同次操作拆到多个不足的库存。

范围为喷洒器同层半径 5 格圆形区域。化肥只用于原版化肥状态为 0 且能生效的活作物；治疗仅在对应病害大于 0 时调用原版效果，通常降低“10 + 开启供料者的农业等级”，随后续喷水继续治疗。不额外发经验，不改原版浇水、产量和手动农业。健康、无水、缺料时不消耗；同轮重叠每株每类只处理一次，避让已排队的手动/批量施肥和治疗动作。

## 管网查看与余料回收

窗口顶部固定显示当前设备、容量和管网概况。默认“设备管理”，不再显示只有当前设备的下拉框。

“管网设备”页：从水泵查看可达喷洒器，从喷洒器查看连接水泵；点击条目查看五类库存、开关、接收设置和可用来源。分页显示设备，停泵或缺水仍保留连通关系，供料能力单独显示。窗口每0.75秒检查连接；本次打开后断开的设备保留并标注不可达，已移除/区域未加载分别提示。窗口关闭后清除这份临时查看记录。

“最近供水周期”基于本次游戏中已观察的分钟供水回调，刚加载时显示尚无记录，不把旧保存的水量当作新供水。可用药肥来源表示具备供料条件，真正消耗仍取决于喷水和作物需求。

在水泵旁打开“管网设备”，选择喷洒器即可直接操作每项的 **项目开关** 和 **泵供开关**：

- 项目关闭：此喷洒器停止该项养护，既不用水泵也不用本机库存；不影响其他喷洒器或其他项目。
- 项目开启、泵供开启：优先用对应水泵药肥，再使用已开启的本机库存。
- 项目开启、泵供关闭：只使用本机库存。首次调整泵供时，已开启的项目会启用本机备用供料。
- 管网总接收关闭时全部泵供关闭；单独打开其中一项只恢复该项，其他项继续关闭。

水泵本身的五个供料开关继续独立生效。远处只改变设置，不远程加料或取回；点击时校验玩家在水泵旁、管路可达、目标仍存在且已加载，避免断管后旧页面误操作。停机或缺水时仍可预先配置连接喷洒器。走近目标后“管理此设备”可打开其操作页。

沿用 schema 3；可选 projectDisabled/networkDisabled 标记只记录新设置。未操作的新开关保留升级前的实际供料行为，不自动开启旧本机库存。

“拆除余料回收”仅有记录时出现；取完最后一条回到设备管理，零余额旧喷壶按钮隐藏。

## 药剂包配方

**50 份采用 1 倍原版药材，200 份采用 4 倍**，已按用户最终选择替换原先小包的 2 倍方案。

| 药剂 | 50 份药材和液体 | 200 份药材和液体 |
| --- | --- | --- |
| 霉菌 | 奶 1 L，无额外水 | 奶 4 L，无额外水 |
| 虫害·香烟 | 水 1 L + 单支香烟 5 支 | 水 4 L + 单支香烟 20 支 |
| 虫害·散烟草 | 水 1 L + 原版烟草 8 次用量 | 水 4 L + 原版烟草 32 次用量 |
| 虫害·嚼烟 | 水 1 L + 原版嚼烟 5 次用量 | 水 4 L + 原版嚼烟 20 次用量 |
| 蚜虫 | 水 1 L + 外用酒精 0.2 L | 水 4 L + 外用酒精 0.8 L |
| 蛞蝓（新增配方） | 水 1 L + 盐 1 个 | 水 4 L + 盐 4 个 |

初次制作另加 **1 块木板 / 2 块木板**；重新装填改为 **1 个对应尺寸空药剂包**，不再用木板。原版没有对应的蛞蝓药制作配方，这里新增盐配方，盐按整件消耗。散烟草/嚼烟沿用原版使用次数，不等于整包数量。

共四类、两种尺寸，含虫害三种材料途径及重新装填，共 24 个配方。无需额外喷壶、桶、锅、制作工具或配方杂志。水和药液仍由可用液体物品提供，配方不消耗装水容器；原版液体机制可累加多个容器。

药剂包用于本扩展设备，不能直接替代手工治病喷雾。用空后变为同尺寸空包，可重新装填任意一种药剂。部分使用保留剩余次数并在名称显示。初始重量 1.3 / 4.6，空包 0.3 / 0.6。旧版随身药剂包在进入游戏或打开管理页时按新定义重算重量，保留剩余份数；储存在其他容器的旧包取到身上后打开管理页即可刷新。

## 消耗倍率、回收与保存

沙盒页 **蘇清的喷洒器养护** 有五项独立倍率，默认均 **1**、范围 **0.01～2**。只改消耗，不改每次药效或库存；一份按整数万分之一记账。原生沙盒更新后下次操作读取新值；升级不写入存档沙盒文件。个人存档可自行调整，例如0.05代表每次消耗0.05份；个人设置不改变发行默认值。

**仅取回或拆除时舍弃不足一份的小数**。例如 12.75 份取回 12 份，舍弃 0.75；正常自动消耗保留小数。取回药剂需足量空药剂包，三类喷雾也支持空喷壶；包装不足不回收、不扣库存。化肥和原版蛞蝓药不需空喷壶。取回关闭该资源的本机库存供给。

不再产生余料包。保留旧 SQSF.CareResidue 定义仅供转换：加入设备时转换整份、舍弃小数，移除旧物品。

独立账本避免复制/搬移物体复制库存。普通拆除后，整份库存进入独立的**拆除余料回收**页面；在任意其他水泵/喷洒器处携带空包装领取。搬回设备开始空库存。Water Pipes 内部 silentRemove 临时替换不触发退料。具体搬移与保存重进的逐项复查步骤保留在验收清单中。

## 验证与停用

离线测试执行游戏 Kahlua、真实 SPlantGlobalObject 和已安装 Water Pipes 供水回调，场景/库存使用受控替身；原生 Java 检查 24 个配方加载、剂量及序列化。窗口 Lua 也执行测试，但不等于游戏内视觉验证。用户于2026-11-02反馈单人游玩暂无问题；该反馈记录整体体验，具体测试范围见 [1.0.0发布说明](docs/RELEASE_1.0.0.md)、[单人复查清单](docs/TESTING_0.3.2.md) 和 [开发说明](docs/DEVELOPMENT.md)。

上游关键源码变化时自动停用，保留回收入口。支持沿用原版农业方法的作物；不支持堆肥或联机，不承诺所有模组果树。

停用前关闭并取回所有设备和待回收库存，处理自定义药剂包及空包。**0.3 保存后不可直接覆盖回 0.2**：账本升级为 schema 3，需转换或恢复升级前完整备份；恢复会回退后续进度。

仓库包含 mods、tools、tests、docs、art、publishing；validation 和 releases 忽略提交。六个透明 128×128 图标由内置 image_gen 根据用户概念图与其他蘇清模组风格生成，[完整提示词](art/icon-prompts.json)。
