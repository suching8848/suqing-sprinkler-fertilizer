# 0.3.1-rc.1 单人验收

1. 制作和再装填50/200份虫害、蚜虫、蛞蝓包，用水分别1/4L；霉菌仍奶1/4L无额外水。木板1/2，药材1/4倍不变。
2. 新满包重量1.3/4.6，空包0.3/0.6。旧随身包打开管理页后按余量重算，不增减份数；收藏标记保留。
3. 右键水泵和喷洒器都默认显示设备管理；顶部无无意义下拉框，连接数只出现一次，旧喷壶0时隐藏领取。
4. 水泵的管网页显示各喷洒器；喷洒器显示上游水泵。点击查看库存/开关/接收设置。多于4台可翻页；未加载区域显示未知库存。
5. 关阀、断管后，已出现的设备标为不可达；恢复后重新连通。停泵或缺水应显示对应状态，不能把连通等同于供料。
6. 刚进档时最近供水周期显示尚无记录，经过下一次游戏分钟供水更新为收到/未收到水。具备材料且开启才显示可用供料，健康作物仍不耗药。
7. 远处只能查看；靠近列表目标后“管理此设备”可用，打开后操作的是目标设备。验证远处点击不能装入/取出材料。
8. 有拆除余额才显示“拆除余料回收”。携带空包装取回最后一条，应回到设备管理并隐藏回收页，窗口不报错。旧喷壶领取后按钮隐藏。
9. 保存退出重进核对库存、开关、药包份数/重量和空包数量。重开窗口验证列表及最近供水状态重新建立。

本版通过离线回归；上述游戏内行为仍待用户验收。库存账本结构未变，不需要重建设备或重开存档。
