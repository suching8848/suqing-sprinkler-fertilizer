# 0.2 单人档测试清单

0.1 施肥和批量农业已收到“测试正常”的反馈。以下验收新增功能；本轮已完整备份升级前存档。进入原单人档即可，同一 Mod ID 已启用，无需重建世界。

## 1. 旧数据和菜单

- 右键现有喷洒器 → **喷洒器施肥与治疗**，应看到化肥、霉菌、虫害、蚜虫、蛞蝓五类及“取回全部”。
- 原有化肥余量和开关保持不变；四种治疗初次均关闭，库存 0。
- 每项显示库存、每次消耗和可用次数。默认每次 1.0000 份。

## 2. 药剂和治疗

准备对应药剂（背包中不要收藏）：

| 作物问题 | 物品 ID |
| --- | --- |
| 霉菌 | Base.GardeningSprayMilk |
| 虫害/苍蝇 | Base.GardeningSprayCigarettes |
| 蚜虫 | Base.GardeningSprayAphids |
| 蛞蝓 | Base.SlugRepellent |

- 在有对应病害、存活的作物旁测试，保持喷洒器供水和出水；范围为同层圆形半径 5 格。
- 加入对应药物，然后开启该项。每次实际喷水，应只扣病株对应药料，病害降低；没有病的作物不扣药。
- 默认 1 倍：满瓶 10 份治疗药剂入库显示 10.0000。一株治疗一次扣 1.0000；药效用原版方法，通常病害降低 10 + 开启时农业等级。病害归零后不再扣。
- 三种喷雾装入时整瓶从背包移除，设备喷壶数 +1；空壶在回收时返还。蛞蝓药没有这个喷壶栏。
- 故意放错误药物/收藏物品，该类加料应不可用；其他类别库存不变。
- 暂停该项、断水、缺药后不应继续治疗；重新开关或补药/供水后恢复。

## 3. 沙盒倍率

已启用 Debug 时打开虫子图标 → **Sandbox** → **蘇清的喷洒器养护**，有五个倍率，默认都 1。改值后点击 **Apply**。这是现有档的设置入口；创建新游戏界面的设置不能代表当前档。

为便于数清，只开启一种治疗、覆盖一株对应病株，暂时停掉覆盖同一株的其他喷洒器。重新打开右键菜单核对每次消耗。

| 设置 | 一株操作一次应扣 |
| --- | --- |
| 0.01 | 0.0100 份 |
| 0.5 | 0.5000 份 |
| 1 | 1.0000 份 |
| 2 | 2.0000 份 |

- 改倍率时库存本身不跳变，只改变每次消耗和可用次数；治疗效果保持一致。
- 例如 2 倍但剩 1 份时应跳过，库存不扣到负数。四类治疗可先测其中一种的全部倍率，再验证其他三类能正常治疗。
- 化肥也有独立倍率；用于尚未施肥的合格作物。同株已有化肥状态时不重复耗料。
- 完成后可恢复喜欢的倍率；保存退出重进后确认倍率仍保留。

## 4. 回收小数与容器

- 低倍率下形成小数余量，再点“取回此类余料和喷壶并关闭”。
- 例如一瓶 10 份药，0.01 倍只治一株一次后剩 9.99：应返还 9 次用量的原版药瓶 + 0.99 份的“喷洒器余料包”，没有额外空壶。
- 将两者重新装入，库存回到 9.9900；余料包不生成喷壶。完全用尽的药瓶，回收时得到原空壶。
- 余料包只能装回本模组喷洒器，不能直接治疗。收藏后不自动选取。卸载模组前应处理掉自定义余料包。
- 少量装药后试普通搬移/拆除：余料和空壶应落在原地；重建后不能再复制一份。

## 5. 保存及兼容

- 保存退出重进，核对余料、喷壶数、开关、倍率及背包余料包名称/数量。
- 双喷洒器重叠时同一轮每株同类只扣一次；正常后续喷水仍可继续治尚未归零的病害。
- 手动/批量治疗和施肥排队期间，喷洒器跳过相关作物。简测原有 Batch Farming 与浇水仍正常。
- 若右下角红错或自动停用，记下发生的步骤；退出后保留 console.txt，反馈物品、病害、倍率和扣料前后值。
