# 0.3.2-rc.1 单人测试

1. 靠近水泵打开管理 → 管网设备 → 选择较远但已连接的喷洒器。五类资源都有“项目”和“泵供”开关，可直接点击，无需走到喷洒器。
2. 让同一喷洒器和水泵都装有霉菌药、旁边有霉菌作物。关霉菌“项目”，经过喷水周期后本机和水泵霉菌药都不消耗，病害不被此喷洒器治疗；其他养护项目仍按需求运行。注意其他喷洒器的覆盖可能仍治疗同一作物。
3. 开霉菌“项目”，关霉菌“泵供”：只从该喷洒器本机库存扣药。再开泵供应优先扣水泵；其他药肥的泵供开关不变。
4. 关管网总接收，再单独开一项泵供：只恢复这一项。项目总开关关闭时，开启泵供不能绕过该项目停用状态。
5. 离开水泵、关阀、断管、移除喷洒器时不能再通过旧条目操作；恢复连接后恢复可操作。远程加料/取回不开放，仍须靠近实际目标。
6. 保存退出重进，核对各喷洒器五项开关、泵供设置、两端库存及原有50份1L/200份4L配方。直接打开喷洒器看到相同设置。
7. 右键可翻耕泥地、已翻耕空地、已有作物应显示“批量农耕”；右键普通道路、木地板、水面和被阻挡的普通泥地不显示。保留其他右键菜单和农耕原功能。
8. 打开制作界面，找到“蘇清的水泵灌溉器升级”：分类旁应显示独立蘇清灌溉图标。药剂包的配方和物品图标保持可用。

离线验证不等于以上游戏内验收。本次已有游戏进程退出记录，未由自动化启动游戏。
