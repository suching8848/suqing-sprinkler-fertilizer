# 0.3.0-rc.2 单人验收

本轮窗口修复优先复测：分别首次打开喷洒器和水泵窗口；有待回收记录时取回最后一份后应自动选回当前设备，窗口仍可继续操作。

0.2 已由用户实测通过。以下针对新增功能，离线检查不代替游戏验收。

1. **旧档与窗口**：右键原喷洒器打开“管理水泵／喷洒器养护”，旧库存/开关保留，每类容量200；水泵1000。连续加料、开关、取回不关闭窗口，大字体下底部状态和按钮可见。
2. **50份制作**：在“蘇清的水泵灌溉器升级”分类，每种小包用1木板，药材为奶1L；香烟5支／散烟草8次／嚼烟5次；酒精0.2L；盐1个。除霉菌外另用水5L。确认产物50份，不需喷壶、锅桶或杂志。
3. **200份制作**：用2木板，药材为奶4L／香烟20支／散烟草32次／嚼烟20次／酒精0.8L／盐4个；除霉菌外水20L。可把水分装多个容器，确认合计扣液体，保留容器，产物200份。
4. **空包循环**：小包先加入10，应剩40，再装完留下一个50容量空包。空包+对应药材液体可再装填，不消耗木板。大包同样留下200空包。空包可换装四类药剂，小空包不能装大配方。
5. **喷壶与满仓**：原版10份喷雾先加入3，瓶内留7；再加入7，只返一个空喷壶。装到200/1000提示满仓，不再扣料；多出的份数留在原包。收藏耗材不使用。
6. **水泵供料**：仅向水泵加药肥并开启，喷洒器“接收管网”开、本机零库存。实际喷水后对应作物生效，扣水泵库存；健康作物不耗药，另一条独立管网不取料；重叠喷洒器同株同类只扣一次。
7. **连接与备用**：停泵、断管、关关键阀门，观察下一次供水周期后不再从该泵取药；重新接通恢复。关闭喷洒器接收管网后，只用已开启的本机库存。水泵不足时本机开启且有料才接替。再测楼上喷洒器及两泵共线。
8. **倍率与取回**：五项默认1、范围0.01～2；选一类改0.5或0.01运行一次，余额保留小数。带足空包/空喷壶取回，仅返整数，舍弃小数并关闭资源；包装不够提示且库存不变。化肥和原版蛞蝓药无需空喷壶。
9. **旧材料与搬移**：旧寄存喷壶领取一次后归零；旧余料包加入只转整份，舍弃小数，不生成新余料包。拆有料设备，在另一个设备窗口选“待回收设备”携带空包装领取，搬回设备不能复制库存。
10. **保存重进**：记录水泵/喷洒器库存、开关、包内余量、空包和待回收余额。保存退出重进核对，再试一次供料与再装填，留意错误计数和console.txt的SQSF报错。

异常时记录步骤、设备类型、药剂、前后数量及截图/报错，先停止重复操作。0.3写入的档不可只换回0.2，需转换或完整备份恢复。
